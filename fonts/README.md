# Fonts

CJK interface fonts that the RustGIS web app downloads when the interface language is Chinese,
Japanese or Korean (browsers can't read installed fonts; the desktop app uses system fonts).

| File | Font | Licence |
| --- | --- | --- |
| `NotoSansSC-Regular.otf` | Noto Sans SC (Simplified Chinese subset) | SIL Open Font License 1.1 |
| `NotoSansJP-Regular.otf` | Noto Sans JP (Japanese subset) | SIL Open Font License 1.1 |
| `NotoSansKR-Regular.otf` | Noto Sans KR (Korean subset) | SIL Open Font License 1.1 |

Source: <https://github.com/notofonts/noto-cjk> (`Sans/SubsetOTF`). Licence text: [OFL.txt](OFL.txt).
